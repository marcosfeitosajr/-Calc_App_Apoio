# Calc App Apoio

Este projeto é uma aplicação [Streamlit](https://streamlit.io/) para cálculo de apoios do tipo POT.

## Como executar

1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Rode a aplicação:
   ```bash
   streamlit run app.py
   ```

O antigo arquivo `Cálculo_POT_UNI.py` foi refatorado e seu código principal encontra-se em `calc_app/pot_calc.py`.
